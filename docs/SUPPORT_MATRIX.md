Windows: controllers in XInput mode are read through Microsoft's XInput API as a generic Xbox-layout controller (input, rumble, battery); XInput cannot identify the model, so model-specific features are Linux-only. This backend is unit-tested but has not been run on Windows hardware. DualSense, DualShock 4 and Switch Pro have no Windows backend yet.
macOS: TuiSense builds and runs (gallery, profiles, reports), but no controller backend is implemented yet.
