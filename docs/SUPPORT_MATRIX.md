Windows: controllers in XInput mode are read through Microsoft's XInput API (input, rumble, battery when reported) with Windows' built-in drivers. The model is named only when the vendor/product IDs of Windows' HID listing identify it exactly; a probable match (such as the shared Xbox 360 ID) stays a generic gamepad until the user confirms it. HID-only controllers (DirectInput or Android modes, DualSense, DualShock 4, Switch Pro) are detected and identified but have no Windows input backend yet. Model-specific features remain Linux-only. Nothing on Windows has been verified on physical hardware yet.
macOS: TuiSense builds and runs (gallery, profiles, reports), but no controller backend is implemented yet.
